dsh-server-log-analyzer

服务器带外日志（BMC / iDRAC / iLO / iBMC / XCC / IPMI SEL / Redfish）与系统日志的硬件初步研判插件 · DSH bundle

安装

dsh plugin --profile desktop add dsh-server-log-analyzer

或从源码安装：

dsh plugin --profile desktop add github:xiaofadefa/dsh-server-log-analyzer

作为插件市场索引源

DSH → 插件 → 发现 → 添加索引源，填入：

https://xiaofadefa.github.io/dsh-server-log-analyzer/index.json
